课间 Study Desk · 大学生学习事务管理
========================================

一个零依赖、零构建的本地学习事务管理应用：
课程 / 活动 / 任务 DDL / 学习计划 / 文件版本管理 / 提醒 / AI 通知录入。
前端为原生 HTML + CSS + ES Modules，后端为 Node.js 原生服务，数据保存在本机。

【运行要求】
- Node.js 18 或更高版本（推荐 20+），下载地址：https://nodejs.org/
- 无需安装任何依赖包，无需构建步骤。

【打开步骤】
1. 解压本压缩包到任意文件夹（路径建议不含特殊字符）。
2. 在该文件夹里打开终端：
   - Windows：在文件夹地址栏输入 cmd 回车，或右键选择“在终端中打开”。
   - macOS / Linux：cd 进入该文件夹。
3. 运行：
       node server.js
   看到启动提示后，浏览器打开：
       http://localhost:5173
4. 登录页有两种进入方式：
   - 输入任意邮箱获取验证码注册（开发模式下验证码会直接显示在页面上）；
   - 或点击“示例空间”一键体验（独立隔离的演示数据，24 小时自动清理）。

【说明】
- 首次启动会自动创建 data/ 文件夹存放数据库与上传文件，全部数据仅在本机。
- 端口固定为 5173；如被占用，请先关闭占用该端口的程序。
- 邮件摘要功能在未配置邮件服务时会如实记录批次并提示，不会假装发送。
- 关闭服务：在终端按 Ctrl + C。
